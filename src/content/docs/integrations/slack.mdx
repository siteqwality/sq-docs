The Slack integration installs an OAuth app into one Slack workspace. Each notification channel you create afterwards specifies a destination Slack channel.

## Install

Only an account admin can install it.

<Steps>

1. Go to **Manage → Integrations** and click the **Slack** card. Optionally type a name (it defaults to the workspace name followed by "Slack"), then click **Add to Slack**.

2. You're sent to Slack's consent screen. Pick the workspace and approve.

3. Slack sends you back to Site Qwality, which finishes the install. The integration appears in your list.

</Steps>

The link to Slack works once, for 10 minutes, and only for the admin who clicked **Add to Slack**. If it expired or was already used, or you cancel on Slack's screen, nothing is connected: click **Add to Slack** again.

The app asks for two scopes: `chat:write` to post, and `chat:write.public` to post in public channels without joining them.

The install runs only from the dashboard, because it is a round trip through Slack in your browser. API keys, API clients and AI assistants get a `403` that says "Connect Slack from the Integrations page in the dashboard."

Org-wide Enterprise Grid installs are not supported yet. Install the app into a single workspace instead.

## Add the bot to private channels

The app can post to any public channel without joining it. For a private channel, add the Site Qwality app to the channel first (from the channel's settings, or with `/invite` and the app's name).

## Add it to a notification group

Integrations deliver nothing on their own. Alerts reach one once it is a channel in a notification group that your monitors use.

<Steps>

1. Go to **Respond → Notifications**. Click a group's name to open it, or click **Add group** to make a new one.

2. Under **Notifications**, click **Add Notification Method**. Set **Notification Type** to **Slack** and choose this integration under **Integration**.

3. In **Channel Name or ID**, enter the Slack channel, such as `#ops` or a channel ID like `C0123456789`.

4. Click **Done editing**, then **Update Group** (**Create Group** for a new group).

</Steps>

Through the API, create the channel with [`POST /notification`](/api-reference/operations/create_notification/):

```bash
curl -X POST https://api.siteqwality.com/notification \
  -H "Authorization: Bearer $SITEQWALITY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "notification_group_id": "<your-group-id>",
    "type": "slack",
    "details": {
      "integration_id": "<slack-integration-id>",
      "channel": "#ops"
    }
  }'
```

`channel` accepts `#name` or a Slack channel ID (`C0123456789`). Channel IDs are robust to renames.

## Message format

Monitor alerts post as a Slack message attachment with a colored bar:

- **Monitor Down** (red): the monitor name, its URL, the time and the failure reason.
- **Monitor Up** (green): the monitor name, its URL, when the outage started and resolved, and the total downtime.

Messages have no buttons and no link back to Site Qwality. A recovery is a new message, not an edit of the down message.

A send is tried once. If Slack rejects or throttles it, there is no later retry.

## Incidents

Incident messages do not use this integration. A service's Slack broadcast target and a Slack contact method each take a bot token and channel that you paste in. Those messages link to the incident in Site Qwality and carry no buttons, because everyone in the channel sees them. Acknowledge and resolve incidents in the dashboard: Slack messages cannot act on an incident. See [Acknowledge from the alert itself](/incident-management/incidents/how-to/one-click-actions/#slack).

## Removing

Go to **Manage → Integrations**, find the Slack integration under **Existing Integrations** and delete it. Through the API, call [`DELETE /integration/{integration_id}`](/api-reference/operations/delete_integration/):

```bash
curl -X DELETE https://api.siteqwality.com/integration/$INTEGRATION_ID \
  -H "Authorization: Bearer $SITEQWALITY_API_KEY"
```

This removes the integration and deletes every channel that used it, so add channels on a different integration first if you don't want to lose alerting. It does not revoke the token in Slack: to remove access, also remove the Site Qwality app from your workspace in Slack.

## Troubleshooting

- **Channel not found.** The channel is private and the app isn't in it, or the name is wrong. Add the app to the channel, or use the channel ID.
- **Posts arrive but rate limited.** Slack throttles bots at ~1 message/sec per channel. Spread alerts across channels if you're firing many at once.
