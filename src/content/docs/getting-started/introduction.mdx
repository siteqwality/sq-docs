SiteQwality is a website monitoring and status-page platform. These docs cover:

- **Uptime monitoring** — HTTP, SSL/TLS, DNS, cron heartbeats, and browser checks.
- **Observability** — metrics, logs, traces, real-user monitoring (RUM), and session replay.
- **Incident management** — incidents, on-call schedules, escalation policies, and notifications.
- **Status pages** — branded public pages with components, incidents, and subscribers.
- **Dashboards** and **integrations**.
