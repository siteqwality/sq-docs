## Base URL

```
https://api.siteqwality.com
```

## Authentication

The API uses bearer tokens. Generate an API key in your account settings and pass it in the `Authorization` header:

```http
Authorization: Bearer <YOUR_API_KEY>
```

## Rate limiting

Requests are rate-limited per API key. Exceeding the limit returns `429 Too Many Requests`.

## Errors

Standard HTTP status codes. Error responses include a JSON body with a human-readable message.
