Site Qwality connects server telemetry with browser experience and monitoring. Start with the [setup guides](/observability/platforms/overview/): create an ingest key, pick your language or platform and send data.

| Area | Use it for |
|---|---|
| [Logs](/observability/logs/overview/) | Search events, extract fields, analyze volume and follow a request's context. |
| [Metrics](/observability/metrics/overview/) | Query gauges, counters and distributions, compare periods and evaluate formulas. |
| [Traces](/observability/traces/overview/) | Follow a request through services, inspect spans and find correlated logs. |
| [Services](/observability/services/) | Service and endpoint RED, versions, deployment markers and dependencies. |
| [Errors](/observability/errors/) | Group backend exceptions and browser issues with lifecycle and ownership. |
| [Alerts and SLOs](/observability/alerts/) | Evaluate thresholds, ratios, distributions and error budgets with explicit missing-data states. |
| [RUM](/observability/rum/overview/) | Browser performance, resources and JavaScript errors. |
| [Session replay](/observability/replay/overview/) | Inspect recorded user interactions subject to consent, sampling and access. |

Telemetry alert rules show their state in the app but do not send notifications yet. Use uptime and incident notifications for paging.

## Send, verify, explore

The OTLP/HTTP origin is `https://otlp.siteqwality.com`, with `/v1/logs`, `/v1/traces` and `/v1/metrics`. JSON, remote-write and platform adapters have their own [routes and contracts](/observability/ingest/).

Use stable `service.name`, `deployment.environment.name` and `service.version`: resource identity joins related signals. Logs need actual trace and span IDs to link to a request. [Correlation](/observability/traces/how-to/correlate-logs/) explains browser opt-in and CORS.

## Control data and cost

Logs and traces are metered in decimal GB and metrics in active series; allowances, retention and limits are in [billing and retention](/observability/billing/).

Configure [processing pipelines](/observability/pipelines/) before expanding collection. Review [access, exports and erasure](/observability/privacy/) and keep ingest keys on servers. Telemetry read restrictions apply across explorers, saved views, exports and correlation.
