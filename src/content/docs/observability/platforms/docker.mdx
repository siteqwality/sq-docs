## 1. Save collector.yaml

The container network can reach this receiver. If host applications need it, publish it on loopback only. To ingest container stdout, add the Collector filelog receiver with read-only mounts for your runtime log files, or use the `docker_logs` source in [Vector](/observability/platforms/vector/).

```yaml
receivers:
  otlp:
    protocols:
      http:
        endpoint: 0.0.0.0:4318
processors:
  memory_limiter:
    check_interval: 1s
    limit_mib: 256
    spike_limit_mib: 64
  resource:
    attributes:
      - {key: service.name, value: "my-service", action: upsert}
      - {key: deployment.environment.name, value: "production", action: upsert}
  batch:
    send_batch_size: 256
    send_batch_max_size: 512
    timeout: 1s
exporters:
  otlphttp/siteqwality:
    endpoint: https://otlp.siteqwality.com
    headers:
      Authorization: "Bearer YOUR_INGEST_KEY"
    compression: gzip
    sending_queue: {enabled: true, queue_size: 1000}
    retry_on_failure: {enabled: true, initial_interval: 1s, max_interval: 30s, max_elapsed_time: 300s}
service:
  pipelines:
    logs:
      receivers: [otlp]
      processors: [memory_limiter, resource, batch]
      exporters: [otlphttp/siteqwality]
    traces:
      receivers: [otlp]
      processors: [memory_limiter, resource, batch]
      exporters: [otlphttp/siteqwality]
    metrics:
      receivers: [otlp]
      processors: [memory_limiter, resource, batch]
      exporters: [otlphttp/siteqwality]
```

## 2. Save compose.yaml

Choose a released Collector version and pin its image digest for production. Keep `collector.yaml` private because it contains the key. Applications in this Compose network send to `http://collector:4318` and need no cloud key.

```yaml
services:
  collector:
    image: otel/opentelemetry-collector-contrib:${COLLECTOR_VERSION:?set a released version}
    command: ["--config=/etc/otelcol-contrib/config.yaml"]
    volumes: ["./collector.yaml:/etc/otelcol-contrib/config.yaml:ro"]
    ports: ["127.0.0.1:4318:4318"]
    restart: unless-stopped
```

## 3. Start and inspect

Enable SDK instrumentation in your app, send a request and check the explorer.

```bash
export COLLECTOR_VERSION=YOUR_RELEASED_COLLECTOR_VERSION
docker compose config
docker compose up -d
docker compose logs --tail=50 collector
```

## See your data

Open [Logs](https://app.siteqwality.com/logs), [Traces](https://app.siteqwality.com/traces) or [Metrics](https://app.siteqwality.com/metrics). New data usually shows up within a minute. Nothing arriving? See [failure handling](/observability/ingest/#failure-handling).

## Production checklist

Store the key in your platform secret mechanism, rotate it when exposed and remove test keys. Set a stable service.name and deployment.environment.name; avoid user IDs or unbounded values in metric labels. Prefer a persistent queue, bounded retries and exporter failure monitoring. Review [redaction and processors](/observability/pipelines/) before increasing traffic.
