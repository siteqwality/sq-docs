This guide covers logs. Replace `YOUR_INGEST_KEY` with your key.

<BeforeYouStart />

## 1. Create an HTTPS drain

Heroku sends Logplex frames with Basic authentication, using the ingest key as the password, so the drain URL is a secret: keep it out of shell history and screenshots, and rotate the key if exposed.

```bash
heroku drains:add 'https://siteqwality:YOUR_INGEST_KEY@otlp.siteqwality.com/v1/heroku' --app YOUR_APP
heroku drains --app YOUR_APP
```

## 2. Generate traffic and verify

Make an application request that emits a log. The drain carries logs only; use an application SDK for traces and metrics. Set service and environment defaults on the ingest key when Logplex does not carry them.

```bash
heroku logs --tail --app YOUR_APP
```

## See your data

Open [Logs](https://app.siteqwality.com/logs). New data usually shows up within a minute. Nothing arriving? See [failure handling](/observability/ingest/#failure-handling).

## Production checklist

Treat the URL that carries the key as a secret, rotate the key when exposed and remove test keys. Keep service and environment names stable and monitor delivery errors. Review [redaction and processors](/observability/pipelines/) before increasing traffic.
