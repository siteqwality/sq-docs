This guide configures logs, traces, metrics. Start with an admitted Site Qwality account and an ingest key from [API keys](https://app.siteqwality.com/account?tab=api-keys). Replace YOUR_INGEST_KEY on your server. Never use a real key in a public example.

## 1. Install the HTTP exporters

Run in an initialized Go module. This self-contained example creates the selected providers explicitly.

```bash
go get go.opentelemetry.io/otel/sdk go.opentelemetry.io/otel/sdk/metric go.opentelemetry.io/otel/sdk/log go.opentelemetry.io/otel/exporters/otlp/otlptrace/otlptracehttp go.opentelemetry.io/otel/exporters/otlp/otlpmetric/otlpmetrichttp go.opentelemetry.io/otel/exporters/otlp/otlplog/otlploghttp
go get go.opentelemetry.io/otel/log
```

## 2. Save as main.go



```go
package main

import (
  "context"
  "log"
  "go.opentelemetry.io/otel/attribute"
  "go.opentelemetry.io/otel/sdk/resource"
  "go.opentelemetry.io/otel/exporters/otlp/otlptrace/otlptracehttp"
  sdktrace "go.opentelemetry.io/otel/sdk/trace"
  "go.opentelemetry.io/otel/exporters/otlp/otlpmetric/otlpmetrichttp"
  sdkmetric "go.opentelemetry.io/otel/sdk/metric"
  "time"
  otellog "go.opentelemetry.io/otel/log"
  "go.opentelemetry.io/otel/exporters/otlp/otlplog/otlploghttp"
  sdklog "go.opentelemetry.io/otel/sdk/log"
)

func main() {
  ctx := context.Background()
  res := resource.NewSchemaless(attribute.String("service.name", "my-service"), attribute.String("deployment.environment.name", "production"))
  te, err := otlptracehttp.New(ctx); if err != nil { log.Fatal(err) }
  tp := sdktrace.NewTracerProvider(sdktrace.WithResource(res), sdktrace.WithBatcher(te))
  defer tp.Shutdown(ctx)
  ctx, span := tp.Tracer("example").Start(ctx, "example.request")
  defer span.End()
  me, metricErr := otlpmetrichttp.New(ctx); if metricErr != nil { log.Fatal(metricErr) }
  mp := sdkmetric.NewMeterProvider(sdkmetric.WithResource(res), sdkmetric.WithReader(sdkmetric.NewPeriodicReader(me)))
  defer mp.Shutdown(ctx)
  counter, counterErr := mp.Meter("example").Int64Counter("example.requests"); if counterErr != nil { log.Fatal(counterErr) }
  counter.Add(ctx, 1)
  le, logErr := otlploghttp.New(ctx); if logErr != nil { log.Fatal(logErr) }
  lp := sdklog.NewLoggerProvider(sdklog.WithResource(res), sdklog.WithProcessor(sdklog.NewBatchProcessor(le)))
  defer lp.Shutdown(ctx)
  var record otellog.Record
  record.SetTimestamp(time.Now())
  record.SetSeverity(otellog.SeverityInfo)
  record.SetBody(otellog.StringValue("Hello from Go"))
  lp.Logger("example").Emit(ctx, record)
}
```

## 3. Configure and send

Providers are created only for the selected signals. In an existing application, install the providers and your HTTP/database instrumentation before serving requests, and shut them down with a bounded context.

```bash
export OTEL_SERVICE_NAME='my-service'
export OTEL_RESOURCE_ATTRIBUTES='deployment.environment.name=production'
export OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf
export OTEL_EXPORTER_OTLP_LOGS_ENDPOINT='https://otlp.siteqwality.com/v1/logs'
export OTEL_EXPORTER_OTLP_LOGS_HEADERS='Authorization=YOUR_INGEST_KEY'
export OTEL_EXPORTER_OTLP_TRACES_ENDPOINT='https://otlp.siteqwality.com/v1/traces'
export OTEL_EXPORTER_OTLP_TRACES_HEADERS='Authorization=YOUR_INGEST_KEY'
export OTEL_EXPORTER_OTLP_METRICS_ENDPOINT='https://otlp.siteqwality.com/v1/metrics'
export OTEL_EXPORTER_OTLP_METRICS_HEADERS='Authorization=YOUR_INGEST_KEY'
export OTEL_LOGS_EXPORTER=otlp
export OTEL_TRACES_EXPORTER=otlp
export OTEL_METRICS_EXPORTER=otlp
go run .
```

## Confirm readable data

Open [Add data](https://app.siteqwality.com/add-data?platform=go), select the signal and choose **Check again**. This reads retained data permitted for your account and member. A permission error is not proof that collection failed. Open the explorer, select your service/environment and a recent window.

- Create an ingest key for this account and only the signals you send. Read-only keys cannot ingest; ingest keys cannot query. Use a separate read-only API key or your signed-in session for exploration.
- A successful OTLP HTTP response is 200 with an ExportResponse. Inspect partialSuccess for rejected records. JSON /ingest and /metrics return 200 with accepted, rejected and errors. Remote-write returns 204 on full acceptance; platform adapters use their own acknowledgement formats.
- Accepted data has been written to storage or durable spill. It can appear later during replay. Acceptance does not mean every record passed validation or that it is already searchable. Retry transient 429/5xx failures with backoff and honor Retry-After; do not blindly resend an entire partially accepted batch.
- Requests allow 4,000,000 wire bytes, up to 40,000,000 inflated bytes for logs/traces or 16,000,000 for metrics, and at most 100:1 inflation. Use gzip or supported deflate on HTTP; Prometheus uses Snappy. Split oversized requests instead of retrying unchanged.
- 401/403: check key, account, signal scope and collection access. 413: reduce batch bytes. 415: check protocol and content type. 429: check quota/cardinality/rate and wait for Retry-After. Persistent 5xx: retain your local buffer and contact support with request time, never the key.

## Production checklist

Store the key in your platform secret mechanism, rotate it when exposed and remove test keys. Set a stable service.name and deployment.environment.name; avoid user IDs or unbounded values in metric labels. Prefer a persistent queue, bounded retries and exporter failure monitoring. Review redaction and processors before increasing traffic.
