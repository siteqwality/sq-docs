## 1. Install

Run this in your app's environment, after your app's own packages are installed. The second line adds instrumentation for the libraries it finds, such as Flask, Django, FastAPI, requests and psycopg.

<Snippet code={install} lang="bash" />

## 2. Configure

Set these where your app runs. Replace `YOUR_INGEST_KEY` with your key and `checkout` with your service name.

<Snippet code={env} lang="bash" />

## 3. Start your app

Put `opentelemetry-instrument` in front of the command that starts your app, for example:

<Snippet code={run} lang="bash" />

Requests to your app and the calls it makes are now traced automatically.

## 4. Send a log

<Snippet code={app} region="log" lang="python" />

Records from the standard `logging` module arrive as logs, linked to the trace of the request that wrote them. Records below the logger's level are not sent, so set it to the lowest level you want to keep.
