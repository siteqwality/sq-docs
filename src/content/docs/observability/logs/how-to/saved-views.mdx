---
title: Save and share views
description: Keep a reusable logs query and display settings without granting extra data access.
last_verified: 2026-10-18
owner: jj
---

Build a useful query in Logs, then use the Saved views control. Choose a name and personal/shared visibility. Save a relative time range for a view that moves with now; an absolute range intentionally pins an incident window.

Views use `/telemetry/views` and `/telemetry/views/{id}`, with the appropriate page and versioned query/display state. Loading a shared view still applies the current member's service/environment/signal restrictions. It does not transfer the creator's data access. Owner/admin mutation rules and conflict behavior are enforced by the API.

Changing the query invalidates its old paging cursor. URL links are for query state, never an ingest key. See [query reference](/observability/query/) and [privacy](/observability/privacy/).
